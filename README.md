# Control-Universal-con-el-Esp-32
Control Universal Domótico IR basado en ESP32-C3 que permite controlar equipos de aire acondicionado Midea, LG y televisores Panasonic mediante señales infrarrojas. Integra Wi-Fi, Sinric Pro, Amazon Alexa y pantalla OLED, ofreciendo control remoto, comandos de voz y gestión local desde una sola plataforma.
